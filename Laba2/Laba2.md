Задание 1.
Задача 3

Текст задачи
Создать класс Name, который хранит фамилию, имя и отчество человека. Некоторые параметры имени могут отсутствовать. 
При выводе объекта необходимо показывать только те части имени, которые заданы.
Создать следующие объекты:
Клеопатра
Пушкин Александр Сергеевич
Маяковский Владимир

Алгоритм решения
Создаётся класс Name с полями для фамилии, имени и отчества. В конструкторе задаются значения этих полей.
Метод toString() формирует строку из имеющихся частей имени. Если фамилия, имя или отчество отсутствуют, 
они не добавляются в результат.
Создаются три объекта класса Name с указанными именами и выводятся на экран.

Задание 2. 
Задача 2

Текст задачи
Создать класс Person, который содержит имя человека в виде объекта класса Name и рост человека.
Создать следующих людей:
Клеопатра, рост 152
Пушкин Александр Сергеевич, рост 167
Маяковский Владимир, рост 189

Алгоритм решения
В классе Person создаётся поле name типа Name и поле height для хранения роста.
При создании объекта Person в него передаётся уже созданный объект Name и значение роста.
Метод toString() выводит имя человека и его рост.
Создаются три объекта класса Person и выводятся на экран.

Задача 3

Текст задачи
Дополнить класс Person возможностью хранить отца человека. Отец также является объектом класса Person.
Если у человека не указана фамилия, но фамилия есть у отца, при выводе необходимо использовать фамилию отца.
Если у человека не указано отчество, а у отца есть имя, необходимо использовать имя отца с окончанием «ович».
Создать следующих людей:
Чудов Иван
Чудов Петр
Борис
Иван является отцом Петра, а Петр является отцом Бориса. Вывести всех созданных людей.

Алгоритм решения
В класс Person добавляется поле father, которое хранит ссылку на объект класса Person.
При выводе объекта проверяется наличие фамилии. Если фамилия отсутствует, берётся фамилия отца.
Затем проверяется наличие отчества. Если отчество отсутствует, берётся имя отца и добавляется окончание «ович».
После этого формируется полное имя человека и выводится вместе с его ростом.
Создаются Иван, Петр и Борис. Для Петра в качестве отца указывается Иван, а для Бориса — Петр.

Задание 3.
Задача 2

Текст задачи
Создать класс Polyline, представляющий ломаную линию, состоящую из массива точек.
Создать первую ломаную через точки {1;5}, {2;8}, {5;3}.
Создать вторую ломаную, у которой первая и последняя точки совпадают с первой и последней точками первой ломаной. 
Средние точки второй ломаной: {2;-5}, {4;-8}.
Изменить первую точку первой ломаной так, чтобы было видно, что обе ломаные используют один и тот же объект точки.

Алгоритм решения
Создаётся класс Point с координатами x и y.
Класс Polyline содержит массив объектов Point. В конструктор можно передать несколько точек.
Создаются три точки первой ломаной. Затем создаётся вторая ломаная, в которую передаются первая 
и последняя точки первой ломаной и две новые точки.
После изменения координат общей первой точки изменяются обе ломаные, так как они содержат ссылку на один 
и тот же объект Point.

Задание 4. 
Задача 9

Текст задачи
Изменить класс Polyline, чтобы ломаную можно было создать без параметров или передав в конструктор
некоторое количество точек.

Алгоритм решения
В классе Polyline создаются два конструктора.
Первый конструктор не принимает параметры и создаёт пустой массив точек.
Второй конструктор принимает несколько объектов Point и сохраняет их в массиве.
После этого можно создать как пустую ломаную, так и ломаную с заданными точками.

Задача 7

Текст задачи
Изменить класс Polyline, чтобы в него можно было добавлять точки после создания объекта и получать общую длину ломаной.
Создать ломаную через точки {1;5}, {2;8}, {5;3}, вывести её длину. Затем добавить точки {5;15}, 
{8;10} и снова вывести длину.

Алгоритм решения
В класс Polyline добавляется метод для добавления новых точек.
При добавлении создаётся новый массив, в который сначала копируются существующие точки, а затем добавляются новые точки.
Для вычисления длины используется метод getLength(). Он последовательно рассматривает соседние точки 
и вычисляет расстояние между ними по формуле расстояния между двумя точками.
Полученные расстояния складываются, в результате получается общая длина ломаной.
