Задание 1. Инкапсуляция
Номер 3. Квадрат и сторона квадрата

Текст задачи
Создать класс «Квадрат», который хранит точку левого верхнего угла и длину стороны. Предусмотреть два конструктора:
с объектом точки и с координатами x и y. Квадрат должен возвращать ломаную по своим углам и позволять получать
и изменять длину стороны. Сторона должна быть положительной; при недопустимом значении выбрасывается исключение.

Алгоритм решения
Создан класс Square. Поля точки и стороны объявлены с модификатором private. Конструкторы позволяют создать квадрат
двумя способами. Метод getSide() возвращает длину стороны, а setSide() изменяет её и проверяет, что значение
положительное. При недопустимом значении выбрасывается IllegalArgumentException. Метод getPolygonalChain()
создаёт ломаную по углам квадрата. Метод area() возвращает площадь.

Задание 2. Разработка структур данных
Номер 4. Бинарное дерево

Текст задачи
Реализовать бинарное дерево поиска. Узел хранит целое значение, родителя, левого и правого потомков.
Реализовать добавление значения, удаление значения, поиск и строковое представление при левостороннем обходе в глубину.
Добавить числа 3, 5, 4, 7, 1, 2 и вывести дерево.

Алгоритм решения
Создан класс BinaryNode. При добавлении большее значение помещается в правое поддерево, а меньшее
или равное — в левое. Метод contains() проверяет наличие значения. Метод remove() удаляет узел,
сохраняя структуру дерева. Метод toString() выводит значения при обходе дерева слева направо.

Задание 3. Наследование
Номер 2. Замкнутая ломаная

Текст задачи
Создать класс-наследник обычной ломаной, который представляет замкнутую ломаную. Длина должна учитывать
также расстояние от последней точки до первой.

Алгоритм решения
Класс ClosedPolyline наследуется от Polyline с помощью extends. Метод getLength() переопределён с помощью @Override:
он получает обычную длину и добавляет расстояние между последней и первой точками.

Задание 4. Создание иерархий
Номер 4. Фигуры

Текст задачи
Разработать классы круга, квадрата, прямоугольника и треугольника. Для каждой фигуры должна рассчитываться площадь.

Алгоритм решения
Создан абстрактный класс Figure с методом area(). Классы Circle, Square, Rectangle и Triangle наследуют этот класс.
Площадь круга вычисляется по формуле πr², квадрата — как произведение стороны на себя, прямоугольника —
как произведение ширины на высоту, треугольника — по координатам его вершин.

Задание 5. Полиморфизм
Номер 5. Измерение длины

Текст задачи
Разработать метод, который принимает объекты, длину которых можно вычислить, и возвращает сумму их длин.
Изменить классы линии и ломаной так, чтобы они подходили для передачи в этот метод.

Алгоритм решения
Создан интерфейс LengthMeasurable с методом getLength(). Классы Line, Polyline и ClosedPolyline реализуют этот интерфейс.
Метод Main.sumLengths() принимает набор объектов общего типа LengthMeasurable и складывает результаты вызова
getLength() для каждого объекта.

Номер 7. Ломай меня полностью

Текст задачи
Разработать метод, который принимает набор объектов, умеющих возвращать ломаную, и объединяет их ломаные в один объект
типа Polyline.

Алгоритм решения
Создан интерфейс PolygonalChainProvider с методом getPolygonalChain(). Классы Line, Polyline, Square и Triangle
реализуют этот интерфейс. Метод Main.mergeAll() получает ломаную каждого объекта и добавляет её точки
в результирующую ломаную.

Задание 6. Полиморфное сравнение
Номер 4. Сравнение ломаных линий

Текст задачи
Переопределить сравнение объектов ломаной так, чтобы две ломаные считались одинаковыми, если все их точки совпадают.

Алгоритм решения
В классе Polyline переопределён метод equals(). Сначала проверяется, ссылаются ли переменные на один объект,
затем проверяется тип объекта. После этого точки сравниваются по порядку с помощью Arrays.equals().
Для согласованной работы переопределён также метод hashCode().

Задание 7. Пакеты
Номер 1. Навести порядок

Текст задачи
Разместить классы по логическим пакетам с именами, содержащими не менее трёх частей.

Алгоритм решения
Классы распределены по пакетам Geometry (геометрические классы), Tree (бинарное дерево)
и Main (главный класс). Каждое имя пакета содержит три части.

Номер 2. Главный метод

Текст задачи
Создать пакет ru.surname.main, в котором находится класс с методом main, а также продемонстрировать работу методов
из заданий блока полиморфизма.

Алгоритм решения
Главный класс Main находится в пакете Main. В методе main() демонстрируется работа классов и интерфейсов,
измерение длины объектов, вычисление общей площади и объединение ломаных.

Номер 3. Возведение в степень

Текст задачи
Создать метод, который принимает две строки с числами X и Y и возвращает X в степени Y. Для преобразования строки
использовать Integer.parseInt, для возведения в степень — Math.pow. Вызвать метод с параметрами командной строки.

Алгоритм решения
В классе Main создан метод power(), который принимает две строки и преобразует их в целые числа с помощью
Integer.parseInt. Для возведения в степень используется Math.pow. Методы parseInt() и pow() вызываются
без указания имени класса благодаря статическому импорту. В текущем варианте программы используются заданные
в коде строки "2" и "5", поэтому ввод с клавиатуры и параметры командной строки не обрабатываются.

Задание 8. Пакетная инкапсуляция
Номер 4. Клонирование точки

Текст задачи
Переопределить метод клонирования точки так, чтобы он возвращал новый объект с копиями значений полей исходной точки.

Алгоритм решения
Класс Point реализует интерфейс Cloneable и переопределяет метод clone(). Метод возвращает новый объект Point
с такими же координатами. При изменении клона исходная точка остаётся без изменений.
