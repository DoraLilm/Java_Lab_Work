Вариант 10 — задачи 1.1 и 1.2 в первом задании;

Задание 1. Обобщённые классы

Номер 1.1. Коробка

Текст задачи
Создать обобщённый класс Box, который хранит один объект.
Предусмотреть методы для помещения объекта в коробку, получения
объекта и извлечения объекта с очисткой коробки. Необходимо
предусмотреть проверку состояния коробки.

Алгоритм решения
Создан обобщённый класс Box<T>. Поле value хранит объект,
а поле filled показывает, заполнена ли коробка. Метод put()
помещает объект в коробку и проверяет, что она пуста. Метод get()
возвращает хранящийся объект без его удаления. Метод take()
возвращает объект и очищает коробку. Если коробка пуста или
уже заполнена, выбрасывается IllegalStateException.

Номер 1.2. Хранилище

Текст задачи
Создать обобщённый класс Storage, который хранит объект
произвольного типа. Предусмотреть метод получения значения,
который возвращает альтернативное значение, если хранилище
не содержит объект.

Алгоритм решения
Создан обобщённый класс Storage<T>. Поле value хранит значение
и объявлено с модификатором private. Конструктор принимает
объект для сохранения. Метод getValue() возвращает сохранённое
значение, если оно не равно null. В противном случае метод
возвращает переданное альтернативное значение.

Задание 2. Обобщённые методы

Номер 2.2. Поиск максимального значения

Текст задачи
Разработать метод, который принимает список коробок с числами
и возвращает максимальное значение среди хранящихся в них
объектов. Метод должен работать с различными числовыми типами.

Алгоритм решения
Создан класс BoxMethods с методом findMaximum(). Метод принимает
список коробок с объектами, наследующими класс Number.
Для получения числового значения используется метод get(),
а для приведения к общему типу — doubleValue().
В цикле сравниваются значения всех коробок и определяется
максимальное. Добавлены проверки на пустой список, null
и незаполненные коробки.

Задание 3. Обобщённые функциональные интерфейсы

Номер 3.1. Преобразование значений

Текст задачи
Разработать обобщённый интерфейс для преобразования объектов.
Создать метод, который принимает список объектов и преобразует
каждый элемент с помощью переданного объекта-преобразователя.
Результат необходимо сохранить в новом списке.

Алгоритм решения
Создан интерфейс Transformer<T, P> с методом apply().
Он принимает объект типа T и возвращает объект типа P.
В классе GenericMethods реализован метод transform().
Метод проходит по исходному списку, применяет преобразование
к каждому элементу и добавляет результат в новый список.
Созданы преобразователи для строк, целых чисел и массивов.

Номер 3.2. Фильтрация значений

Текст задачи
Разработать обобщённый интерфейс для проверки условия.
Создать метод, который принимает список объектов и условие,
оставляя в результате только элементы, удовлетворяющие ему.

Алгоритм решения
Создан интерфейс Condition<T> с методом test().
Метод filterValues() класса GenericMethods проверяет каждый
элемент исходного списка с помощью переданного условия.
Если метод test() возвращает true, элемент добавляется
в результирующий список. Созданы условия для строк,
целых чисел и массивов.

Номер 3.3. Объединение значений

Текст задачи
Разработать обобщённый интерфейс для объединения двух объектов.
Создать метод, который последовательно объединяет элементы
списка с использованием переданного объекта-объединителя.
Также предусмотреть возможность работы с пустым списком.

Алгоритм решения
Создан интерфейс Combiner<T> с методом combine().
Метод reduce() класса GenericMethods принимает список,
начальное значение и объект-объединитель. В цикле каждый
элемент объединяется с текущим результатом. Полученное значение
сохраняется и используется на следующей итерации.
Для пустого списка возвращается начальное значение.
Созданы объединители для строк и целых чисел.

Номер 3.4. Создание коллекций

Текст задачи
Разработать обобщённые интерфейсы для создания результата
и добавления в него элементов. Создать метод, который принимает
список, фабрику результата и объект для добавления элементов.
Результат должен быть представлен в виде коллекции.

Алгоритм решения
Созданы интерфейсы ResultFactory<R> и ResultWriter<R, T>.
Первый интерфейс содержит метод create(), который создаёт
результат. Второй содержит метод add(), который добавляет
элемент в результат. В классе GenericMethods реализован
метод collectValues(). Он создаёт коллекцию с помощью фабрики,
а затем последовательно добавляет в неё элементы списка.
Созданы фабрики и обработчики для группировки чисел,
группировки строк и получения множества уникальных строк.
