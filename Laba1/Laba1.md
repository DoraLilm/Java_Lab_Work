# Задание 1. Методы

## Задача 2
### Текст задачи
Сумма знаков. Дана сигнатура метода: `public int sumLastNums (int x)`. Необходимо реализовать метод таким образом, 
чтобы он возвращал результат сложения двух последних знаков числа x, предполагая, что знаков в числе не менее двух. 
Пример: x=4568, результат: 14.

### Алгоритм решения
Метод получает целое число x. Последняя цифра — это остаток от деления на 10. Предпоследнюю получаем в два шага: 
делим число на 10 (последняя цифра отбрасывается) и снова берём остаток от деления на 10. 
Метод возвращает сумму этих двух цифр.

## Задача 4
### Текст задачи
Есть ли позитив. Дана сигнатура метода: `public boolean isPositive (int x)`. Необходимо реализовать метод таким образом,
чтобы он принимал число x и возвращал true, если оно положительное. 
Примеры: x=3 — результат true; x=-5 — результат false.

### Алгоритм решения
Метод сравнивает переданное число x с нулём. Если x больше нуля, возвращается true, иначе false. 
Отдельный if не нужен: сравнение `x > 0` само по себе даёт boolean.

## Задача 6
### Текст задачи
Большая буква. Дана сигнатура метода: `public boolean isUpperCase (char x)`. Необходимо реализовать метод таким образом,
чтобы он принимал символ x и возвращал true, если это большая буква в диапазоне от 'A' до 'Z'. 
Примеры: x='D' — результат true; x='q' — результат false.

### Алгоритм решения
Метод получает символ x. Символы можно сравнивать как числа, потому что у каждого есть свой код, 
а коды больших латинских букв идут подряд. Проверяем два условия сразу: символ не меньше 'A' и не больше 'Z'. 
Если оба выполнены — true, иначе false.

## Задача 8
### Текст задачи
Делитель. Дана сигнатура метода: `public boolean isDivisor (int a, int b)`. Необходимо реализовать метод таким образом, 
чтобы он возвращал true, если любое из принятых чисел делит другое нацело. 
Примеры: a=3, b=6 — результат true; a=2, b=15 — результат false.

### Алгоритм решения

Оба варианта нужны, потому что заранее неизвестно, какое число больше. 
Метод возвращает результат проверки.

## Задача 10
### Текст задачи
Многократный вызов. Дана сигнатура метода: `public int lastNumSum(int a, int b)`. 
Необходимо реализовать метод таким образом, чтобы он считал сумму цифр двух чисел из разряда единиц.
Выполните с его помощью последовательное сложение пяти чисел и результат выведите на экран. 
Постарайтесь выполнить задачу, используя минимально возможное количество вспомогательных переменных.

### Алгоритм решения
Метод берёт у обоих чисел остаток от деления на 10 (это и есть цифра единиц) и возвращает их сумму. 
В главном методе заведена одна переменная, в неё записано первое число, дальше метод вызывается четыре раза подряд: 
результат каждого вызова становится первым аргументом следующего. 
Так пять чисел складываются по цепочке, и лишние переменные не нужны.

# Задание 2. Условия

## Задача 2
### Текст задачи
Безопасное деление. Дана сигнатура метода: `public double safeDiv (int x, int y)`. 
Необходимо реализовать метод таким образом, чтобы он возвращал деление x на y, и при этом гарантировал,
что не будет выкинута ошибка деления на 0. При делении на 0 следует вернуть из метода число 0. 
Примеры: x=5, y=0 — результат 0; x=8, y=2 — результат 4.

### Алгоритм решения
Метод получает делимое и делитель. Сначала проверяем делитель на ноль: если он нулевой, 
возвращаем 0 и до деления дело не доходит, поэтому ошибки не будет. Иначе делим, предварительно приведя x к double,
— без этого два целых числа поделились бы нацело и дробная часть потерялась.

## Задача 4
### Текст задачи
Строка сравнения. Дана сигнатура метода: `public String makeDecision (int x, int y)`. 
Необходимо реализовать метод таким образом, чтобы он возвращал строку, которая включает два принятых методом числа 
и корректно выставленный знак операции сравнения (больше, меньше или равно).
Примеры: x=5, y=7 — результат "5 < 7"; x=8, y=-1 — результат "8 > -1"; x=4, y=4 — результат "4 == 4".

### Алгоритм решения
Метод получает два числа и проверяет их по очереди: если x меньше y, собирается строка со знаком «меньше», 
если больше — со знаком «больше». Если не выполнилось ни одно условие, значит числа равны, 
и возвращается строка со знаком равенства. Третью проверку писать не нужно — равенство остаётся единственным вариантом. 
Числа склеиваются со строкой через `+` и сами превращаются в текст.

## Задача 6
### Текст задачи
Тройная сумма. Дана сигнатура метода: `public boolean sum3 (int x, int y, int z)`. 
Необходимо реализовать метод таким образом, чтобы он возвращал true, 
если два любых числа (из трёх принятых) можно сложить так, чтобы получить третье. 
Примеры: x=5, y=7, z=2 — результат true; x=8, y=-1, z=4 — результат false.

### Алгоритм решения
Метод получает три числа и проверяет три варианта: x+y равно z, x+z равно y, y+z равно x. 
Какое из чисел окажется суммой двух других, заранее неизвестно, поэтому перебираются все комбинации. 
Условия объединены через ИЛИ — хватит одного совпадения, чтобы вернуть true.

## Задача 8
### Текст задачи
Возраст. Дана сигнатура метода: `public String age (int x)`. Необходимо реализовать метод таким образом, 
чтобы он возвращал строку, в которой сначала будет число x, а затем одно из слов: год, года, лет. 
Слово «год» добавляется, если число x заканчивается на 1, кроме числа 11. Слово «года» добавляется, 
если число x заканчивается на 2, 3 или 4, кроме чисел 12, 13, 14. Слово «лет» добавляется во всех остальных случаях. 
Примеры: x=5 — "5 лет"; x=31 — "31 год"; x=44 — "44 года".

### Алгоритм решения
Метод смотрит на последнюю цифру числа — берёт остаток от деления на 10. Если это 1 и само число не 11, 
возвращается форма «год». Если 2, 3 или 4 и число не 12, 13 и не 14 — «года». Во всех остальных случаях — «лет». 
Числа 11–14 проверяются отдельно, потому что цифра у них подходящая, а читаются они с формой «лет».

## Задача 10
### Текст задачи
Вывод дней недели. Дана сигнатура метода: `public void printDays (String x)`. 
В качестве параметра метод принимает строку, в которой записано название дня недели. 
Необходимо реализовать метод таким образом, чтобы он выводил на экран название переданного в него дня 
и всех последующих до конца недели дней. Если в качестве строки передан не день, 
то выводится текст «это не день недели». Первый день — понедельник, последний — воскресенье. 
Вместо if в данной задаче используйте switch.

### Алгоритм решения
Метод получает название дня и ищет его в switch, где ветки идут по порядку от понедельника к воскресенью. 
Оператор break стоит только в последней ветке, поэтому после нужного дня выполнение проваливается в следующие ветки 
и печатает все оставшиеся дни до конца недели. Обычно проваливание считают ошибкой, 
но здесь оно и есть решение — цикл не понадобился. 
Если день не совпал ни с одним case, срабатывает default и выводится «это не день недели».

## Задача 10
### Текст задачи

чтобы он генерировал случайное число от 0 до 9, далее считывал с консоли введённое пользователем число и выводил,

### Алгоритм решения

а приведение к int отбрасывает дробную часть — остаётся целое от 0 до 9. Дальше работает бесконечный цикл: 
считывается введённое число (с проверкой, что это действительно число) и увеличивается счётчик попыток. 
Если число совпало с загаданным, выводится сообщение и количество попыток, а цикл прерывается через break. 
Если не совпало, выводится просьба ввести ещё раз. Цикл бесконечный, 
потому что заранее неизвестно, сколько будет попыток.

# Задание 4. Массивы

## Задача 2
### Текст задачи
Поиск последнего значения. Дана сигнатура метода: `public int findLast (int[] arr, int x)`. 
Необходимо реализовать метод таким образом, чтобы он возвращал индекс последнего вхождения числа x в массив arr. 
Если число не входит в массив, возвращается -1. Пример: arr=[1,2,3,4,2,2,5], x=2, результат: 5.

### Алгоритм решения
Заводится переменная для ответа со значением -1. Цикл проходит массив с начала, 
и при каждом совпадении элемента с искомым числом в неё записывается индекс, затирая предыдущий. 
Идём слева направо, поэтому в конце там остаётся индекс последнего совпадения. Если совпадений не было, вернётся -1.

## Задача 4
### Текст задачи
Добавление в массив. Дана сигнатура метода: `public int[] add (int[] arr, int x, int pos)`. 
Необходимо реализовать метод таким образом, чтобы он возвращал новый массив, 
который будет содержать все элементы массива arr, однако в позицию pos будет вставлено значение x. 
Пример: arr=[1,2,3,4,5], x=9, pos=3, результат: [1,2,3,9,4,5].

### Алгоритм решения
Длину массива в Java изменить нельзя, поэтому создаётся новый массив на одну ячейку длиннее. 
Первый цикл копирует элементы левее позиции вставки — их индексы не меняются. 
Затем в ячейку pos записывается новое число. Второй цикл копирует оставшийся хвост, 
но каждый элемент сдвигается на одну позицию вправо, чтобы освободить место. 
Возвращается новый массив, исходный не меняется.

## Задача 6
### Текст задачи
Реверс. Дана сигнатура метода: `public void reverse (int[] arr)`. Необходимо реализовать метод таким образом, 
чтобы он изменял массив arr. После проведённых изменений массив должен быть записан задом-наперёд. 
Пример: arr=[1,2,3,4,5], результат: arr=[5,4,3,2,1].

### Алгоритм решения
Элементы меняются местами попарно: первый с последним, второй с предпоследним и так далее. 
Индекс парного элемента считается как длина массива минус текущий индекс и минус единица. 
Обмен идёт через временную переменную, иначе одно из значений затёрлось бы. Цикл доходит только до середины: 
если пройти массив целиком, каждая пара обменяется дважды и всё вернётся как было. Метод ничего не возвращает, 
он меняет сам переданный массив, и дополнительно печатает результат.

## Задача 8
### Текст задачи
Объединение. Дана сигнатура метода: `public int[] concat (int[] arr1, int[] arr2)`. 
Необходимо реализовать метод таким образом, чтобы он возвращал новый массив, 
в котором сначала идут элементы первого массива (arr1), а затем второго (arr2). 
Пример: arr1=[1,2,3], arr2=[7,8,9], результат: [1,2,3,7,8,9].

### Алгоритм решения

Первый цикл копирует первый массив в начало — там индексы совпадают. Второй цикл заполняет остаток: 
счётчик считает позиции уже в новом массиве и стартует с той ячейки, где закончился первый массив, 
а индекс во втором массиве получается вычитанием этого смещения.

## Задача 10
### Текст задачи
Удалить негатив. Дана сигнатура метода: `public int[] deleteNegative (int[] arr)`. 
Необходимо реализовать метод таким образом, чтобы он возвращал новый массив, 
в котором записаны все элементы массива arr кроме отрицательных. 
Пример: arr=[1,2,-3,4,-2,2,-5], результат: [1,2,4,2].

### Алгоритм решения
Массив проходится дважды. Первый раз только считается количество неотрицательных элементов — длину нового массива 
нужно знать заранее, потом её не изменить. По этому количеству создаётся массив, 
и второй проход копирует в него подходящие элементы. Отдельная переменная следит, в какую ячейку нового массива писать, 
потому что номера в двух массивах не совпадают: отрицательные пропускаются.
