Задание 1. Методы
Задача 3
Текст задачи

Букву в число. Дана сигнатура метода: public int charToNum(char x). Необходимо реализовать метод таким образом, чтобы он принимал символ цифры от '0' до '9' и преобразовывал его в соответствующее число. Например: x='3', результат: 3.

Алгоритм решения

Метод получает символ x. В Java символы имеют числовые коды. Код символа '0' является начальным для цифр, поэтому из кода переданного символа вычитается код '0'. Например, для '3' получается число 3. Метод возвращает полученное число.

Задача 4
Текст задачи

Есть ли позитив. Дана сигнатура метода: public boolean isPositive(int x). Необходимо реализовать метод таким образом, чтобы он возвращал true, если число x положительное, и false в остальных случаях.

Алгоритм решения

Метод сравнивает число x с нулём. Условие x > 0 сразу даёт логическое значение true или false, поэтому дополнительная конструкция if не требуется. Для x=3 результатом будет true.

Задача 6
Текст задачи

Большая буква. Дана сигнатура метода: public boolean isUpperCase(char x). Необходимо реализовать метод таким образом, чтобы он возвращал true, если символ является большой латинской буквой от 'A' до 'Z', и false в остальных случаях.

Алгоритм решения

Метод получает символ x. Символы можно сравнивать между собой, так как каждый символ имеет числовой код. Проверяется, что x находится между 'A' и 'Z' включительно. Если оба условия выполняются, метод возвращает true.

Задача 8
Текст задачи

Делитель. Дана сигнатура метода: public boolean isDivisor(int a, int b). Необходимо реализовать метод таким образом, чтобы он возвращал true, если одно из двух чисел делится на другое нацело, и false в противном случае.

Алгоритм решения

Для проверки деления нацело используется оператор %, который возвращает остаток от деления. Если остаток равен 0, значит число делится нацело. Проверяются два варианта: a делится на b или b делится на a. Если хотя бы одно условие выполняется, результатом будет true.

Задача 10
Текст задачи

Многократный вызов. Дана сигнатура метода: public int lastNumSum(int a, int b). Необходимо реализовать метод таким образом, чтобы он возвращал сумму цифр двух чисел из разряда единиц. С помощью метода необходимо выполнить последовательное сложение пяти чисел, используя минимальное количество вспомогательных переменных.

Алгоритм решения

Метод получает два числа. Последняя цифра первого числа получается с помощью a % 10, а последняя цифра второго — с помощью b % 10. После этого эти две цифры складываются.

В main используется одна переменная total. Сначала в неё записывается число 5. Затем к результату последовательно применяются числа 11, 123, 14 и 1. Результат каждого вызова снова записывается в total, поэтому дополнительные переменные не нужны.

Задание 2. Условия
Задача 1
Текст задачи

Модуль числа. Дана сигнатура метода: public int abs(int x). Необходимо реализовать метод таким образом, чтобы он возвращал абсолютное значение числа x, то есть число без отрицательного знака.

Алгоритм решения

Метод проверяет, меньше ли x нуля. Если число отрицательное, перед ним ставится знак минус, благодаря чему оно становится положительным. Если число уже положительное или равно нулю, оно возвращается без изменений.

Задача 4
Текст задачи

Строка сравнения. Дана сигнатура метода: public String makeDecision(int x, int y). Необходимо реализовать метод таким образом, чтобы он возвращал строку с двумя числами и правильным знаком сравнения: <, > или ==.

Алгоритм решения

Сначала проверяется, меньше ли x числа y. Если да, возвращается строка с символом <. Затем проверяется, больше ли x числа y. Если да, используется символ >. Если оба условия ложны, значит числа равны, поэтому возвращается строка со знаком ==.

Задача 5
Текст задачи

Максимум из трёх. Дана сигнатура метода: public int max3(int x, int y, int z). Необходимо реализовать метод таким образом, чтобы он возвращал максимальное из трёх чисел.

Алгоритм решения

Сначала переменная max получает значение первого числа x. Затем y сравнивается с текущим максимумом. Если y больше, значение max заменяется на y. После этого таким же образом проверяется z. В конце max содержит самое большое из трёх чисел.

Задача 7
Текст задачи

Сумма двух чисел. Дана сигнатура метода: public int sum2(int x, int y). Необходимо реализовать метод таким образом, чтобы он возвращал сумму двух чисел, но если сумма находится в диапазоне от 10 до 19 включительно, возвращал число 20.

Алгоритм решения

Сначала вычисляется сумма x + y и сохраняется в переменной sum. Затем проверяется, находится ли она между 10 и 19. Если находится, метод возвращает 20. В остальных случаях возвращается обычная сумма.

Задача 9
Текст задачи

День недели. Дана сигнатура метода: public String day(int x). Необходимо реализовать метод таким образом, чтобы по числу от 1 до 7 он возвращал название соответствующего дня недели. Если число не соответствует дню недели, необходимо вернуть сообщение это не день недели.

Алгоритм решения

Для выбора одного из нескольких вариантов используется switch. Для каждого числа от 1 до 7 предусмотрен отдельный case: от понедельника до воскресенья. Если значение не совпало ни с одним вариантом, выполняется default и возвращается сообщение о том, что это не день недели.

Задание 3. Циклы
Задача 2
Текст задачи

Числа наоборот. Дана сигнатура метода: public String reverseListNums(int x). Необходимо реализовать метод таким образом, чтобы он возвращал строку, содержащую все числа от x до 0 включительно. Например, при x=5 результатом является 5 4 3 2 1 0.

Алгоритм решения

Создаётся строковая переменная result, изначально содержащая пустую строку. Цикл while выполняется, пока x не станет меньше нуля. На каждой итерации текущее значение x добавляется в строку, после чего x уменьшается на единицу. Поэтому при x=5 последовательно добавляются числа 5, 4, 3, 2, 1 и 0.

Задача 3
Текст задачи

Чётные числа. Дана сигнатура метода: public String chet(int x). Необходимо реализовать метод таким образом, чтобы он возвращал строку со всеми чётными числами от 0 до x включительно.

Алгоритм решения

Создаётся пустая строка result. Цикл for начинается с 0 и на каждой итерации увеличивает значение i сразу на 2. Поэтому переменная принимает только чётные значения: 0, 2, 4, 6 и так далее. Каждое значение добавляется в строку.

Задача 6
Текст задачи

Одинаковость. Дана сигнатура метода: public boolean equalNum(int x). Необходимо реализовать метод таким образом, чтобы он возвращал true, если все цифры числа одинаковые, и false, если хотя бы одна цифра отличается. Например, 1111 даёт true.

Алгоритм решения

Сначала из числа выделяется последняя цифра с помощью % 10. Она сохраняется в переменной lastNum и используется как образец для сравнения. Затем последняя цифра удаляется из числа с помощью деления на 10.

Цикл while по очереди получает остальные цифры числа. Каждая цифра сравнивается с lastNum. Если найдена отличающаяся цифра, сразу возвращается false. Если все цифры совпали, цикл заканчивается и метод возвращает true.

Задача 8
Текст задачи

Левый треугольник. Дана сигнатура метода: public void leftTriangle(int x). Необходимо реализовать метод таким образом, чтобы он выводил треугольник из символов *, имеющий x строк. Количество звёздочек в каждой строке должно совпадать с номером строки.

Алгоритм решения

Используются два вложенных цикла for. Внешний цикл отвечает за количество строк. Внутренний цикл отвечает за количество звёздочек в текущей строке. В первой строке выводится одна звёздочка, во второй — две, в третьей — три и так далее. После завершения внутреннего цикла выполняется println(), который переносит вывод на следующую строку.

Задача 9
Текст задачи

Правый треугольник. Дана сигнатура метода: public void rightTriangle(int x). Необходимо реализовать метод таким образом, чтобы он выводил треугольник из символов * высотой x, выровненный по правому краю.

Алгоритм решения

Используются два внутренних цикла. Первый выводит необходимое количество пробелов перед звёздочками. Количество пробелов уменьшается с каждой новой строкой. Второй цикл выводит звёздочки: в первой строке одну, во второй две, в третьей три и так далее. Благодаря пробелам треугольник получается выровненным по правому краю.

Задание 4. Массивы
Задача 1
Текст задачи

Поиск первого значения. Дана сигнатура метода: public int findFirst(int[] arr, int x). Необходимо реализовать метод таким образом, чтобы он возвращал индекс первого вхождения числа x в массив arr. Если число отсутствует, возвращается -1.

Алгоритм решения

Цикл for проходит массив от начала до конца. На каждой итерации текущий элемент сравнивается с x. Если значения совпадают, метод сразу возвращает текущий индекс. Поэтому первое найденное совпадение и будет первым вхождением. Если цикл закончился и совпадения не было, возвращается -1.

Задача 2
Текст задачи

Поиск последнего значения. Дана сигнатура метода: public int findLast(int[] arr, int x). Необходимо реализовать метод таким образом, чтобы он возвращал индекс последнего вхождения числа x в массив arr. Если число отсутствует, возвращается -1.

Алгоритм решения

Переменная index изначально равна -1. Цикл проходит массив слева направо. Когда находится x, в index записывается его текущий индекс. Если такое число встречается ещё раз, старый индекс заменяется новым. Поэтому после завершения цикла в index остаётся индекс последнего вхождения.

Задача 4
Текст задачи

Добавление в массив. Дана сигнатура метода: public int[] add(int[] arr, int x, int pos). Необходимо реализовать метод таким образом, чтобы он возвращал новый массив, содержащий все элементы исходного массива, но в позицию pos было вставлено значение x. Например: arr=[1,2,3,4,5], x=9, pos=3, результат: [1,2,3,9,4,5].

Алгоритм решения

Размер обычного массива в Java изменить нельзя, поэтому создаётся новый массив newArr, длина которого на одну позицию больше исходного.

Первый цикл копирует элементы до позиции pos. Затем в newArr[pos] записывается новое значение x. Второй цикл переносит оставшиеся элементы исходного массива на одну позицию вправо. После этого новый массив возвращается из метода.

Задача 7
Текст задачи

Реверс массива. Дана сигнатура метода: public int[] reverseBack(int[] arr). Необходимо реализовать метод таким образом, чтобы он возвращал новый массив, в котором элементы исходного массива расположены в обратном порядке.

Алгоритм решения

Создаётся новый массив newArr такого же размера, как arr. Цикл проходит исходный массив с начала. Для каждого элемента используется индекс arr.length - 1 - i, который указывает на соответствующий элемент с конца исходного массива. Поэтому первый элемент нового массива получает последний элемент исходного, второй — предпоследний и так далее.

Задача 10
Текст задачи

Удалить негатив. Дана сигнатура метода: public int[] deleteNegative(int[] arr). Необходимо реализовать метод таким образом, чтобы он возвращал новый массив, содержащий все элементы исходного массива, кроме отрицательных. Например: arr=[1,2,-3,4,-2,2,-5], результат: [1,2,4,2].

Алгоритм решения

Массив проходитcя два раза. В первом цикле подсчитывается количество неотрицательных элементов. Это необходимо для определения размера нового массива. Затем создаётся newArr нужного размера.

Во втором цикле снова просматриваются элементы исходного массива. Если элемент больше или равен нулю, он записывается в новый массив. Переменная index показывает, в какую позицию нового массива нужно записать следующий подходящий элемент. В результате отрицательные числа не попадают в новый массив.
